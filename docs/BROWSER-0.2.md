# 全量浏览器 0.2

此版本完成资源目录与工作台改造，独立原生预览处于实验接入状态。当前没有运行中的游戏进程，不能确认实际窗口画面、VFX 通道或角色槽清理已正确。

## 浏览与制作

顶部为工程、编辑、预览、索引、窗口和设置菜单；下一行为全部、地区、怪物、副本、技能、状态、装备、收藏、最近及未分类栏目。栏目仅切换素材，不更改右侧工程。

下方三栏为来源树、特效列表和常驻工作台。可拖动分隔线改变宽度；预览区与图层区之间也可拖动。窗口菜单控制面板显隐、预览弹出和布局保存／重置。

单击列表播放素材，双击或“加入组合”才新增图层。播放素材不会调用工程变更或撤销历史；素材预览和组合预览通过协调器互斥。资源详情支持复制标识、重命名、收藏、自定义地区／怪物／副本标签，以及单独检查编辑支持。

0.3.0 起，自身模式直接创建角色 VFX，无需装备承载，也不重绘角色。素材浏览、图层调整和组合预览均不依赖导出目标；最后通过“工程 → 装备绑定与 PMP 导出”选择装备。已有集合保留，仅临时注册预览资源；停止后清理本插件映射。独立视图同样尝试直接向角色副本创建 VFX，实际粒子通道仍待验证。

## 全量发现与分类证据

扫描枚举本地各扩展包的索引，按归档分片及偏移去重，先解压标准资源首块识别 AVFX，再读取完整 AVFX 并计算内容摘要。文件名未知也保留定位引用；同内容条目折叠，同时保留所有路径和物理位置。

本机完整扫描结果为 1,802,972 条归档记录、56,923 个不同内容的 AVFX、0 个失败。缓存绑定包版本、索引／数据文件大小及修改时间；不同安装或资源更新后自动拒绝旧缓存。归档引用还校验内容摘要，不能直接读取旧版本偏移。

技能／状态来自表格和时间线；地区来自场景文件及其引用链；副本由 ContentFinderCondition 与地区关联。具有明确 Level → BNpcBase → Territory 关联的怪物，其相关特效可以间接归入地区和副本；服务端生成且无本地关联证据的怪物不强行分类。

怪物资源快照随包提供，来源提交为 `05f6eb0cce19a6a91ae275bce609299d573914b3`。本机文件存在性会重新检查；快照不是国服特效归属的完整权威表。设置中的联网更新固定到上游提交，两个 JSON 均验证、写入后才切换选择指针。默认无需联网。

每条关联保留直接引用、间接关联或用户标注，以及一条代表性证据链；同一来源经过多条资源路径时不重复堆叠。一个资源可以属于多个来源。没有可靠分类的条目始终能在“全部／未分类”中找到。

本次交付缓存包含 32,349 个已关联特效和 24,574 个未分类特效，并已抽查 100 个分散归档资源的摘要。缓存压缩后随插件提供；只在安装资源指纹一致时复用，否则后台重新扫描。

扫描支持暂停、取消和检查点续扫。来源关联使用独立后台任务；总进度和失败记录可在“索引诊断”查看。来源归属不完整不等于资源文件缺失；归档覆盖完整也不意味着每项可播放或可编辑。

## 独立预览的实际边界

适配器创建原生 CharaView，从本地角色复制模型数据，并将其渲染目标的纹理交给 ImGui。包含旋转、平移、缩放、重置、预设取景、背景及二维参考网格。空场景当前通过隐藏角色模型进行探测。

CharaView 使用客户端共用的有限角色视图槽；这些槽位与角色界面、试穿及肖像界面有关，不能认定为插件独占资源。[FFXIVClientStructs CharaView 定义](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/UI/Misc/CharaView.cs)

当前尝试使用空闲的槽 7，遇到占用会拒绝启动，游戏接管时停止。尚需实测视图争用时的原生相机资源清理。取景目前使用重置与预设距离，不是根据所有动态粒子边界计算的自动取景。

接入了原生纹理不代表已证明 VFX 会被该渲染通道正确绘制。透明粒子、深度、隐藏角色后特效是否保留，以及临时集合对预览副本的应用，均标为待游戏内验证。没有使用截图、主画面裁切或模型替代图充当特效预览。

## 工程与验证

工程格式升级为版本 2，旧版本自动转换路径引用并保留图层设置。新工程可以保存无路径归档引用。若更新游戏后该引用失效，可选择新素材并使用“用选中素材重新绑定来源”，保留已有位置、旋转、颜色等参数。

测试入口：

```powershell
dotnet run --project tests/AetherVfx.Tests -c Release -- ..\originals
dotnet run --project tools/AetherVfx.Cli -c Release -- scan F:\FF14\Game\game\sqpack artifacts\full-index.json
dotnet run --project tools/AetherVfx.Cli -c Release -- classify F:\FF14\Game\game\sqpack src\AetherVfx.Plugin\assets artifacts\classified-index.json
dotnet run --project tools/AetherVfx.Cli -c Release -- merge-index artifacts\full-index.json artifacts\classified-index.json artifacts\catalog-index.json
```

自动测试包括以模拟预览适配器连续切换 100 次；该项只证明协调器的互斥和清理逻辑，实际原生实例、显存和画面仍按 [验收清单](ACCEPTANCE.md) 检查。
