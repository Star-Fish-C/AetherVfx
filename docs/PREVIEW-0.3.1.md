# 0.3.1 预览诊断版

用户报告 0.3.0 创建预览后仍没有可见特效，并要求独立的空场地窗口，只显示特效。该问题尚未通过游戏画面验证解决，不能将此版本标记为完整预览功能交付。

本机 Dalamud 日志在 2026-10-26 14:40–14:41 记录了资源映射及原生 VFX 对象创建成功，但没有 AVFX 资源实例、实际加载文件或根坐标记录。因此现有证据不足以区分文件未加载、坐标或挂点不正确、上下文条件未满足，以及粒子渲染通道问题。

## 本次变更

- 自身模式默认每帧将 VFX 根坐标和朝向同步到本地角色，并更新变换；可取消以保留资源自己的根坐标行为。资源内部骨骼挂点、世界坐标节点及事件条件仍可能影响可见性。
- 自身面板提供“测试自身光环（原始游戏路径）”，直接播放 `vfx/common/eff/dk10ht_wra0c.avfx`，用于与常规虚拟路径播放对照，不改工程、不选择装备。
- 播放一秒后记录 AVFX 资源句柄状态、实际文件和 VFX 根坐标；自然结束记录最后诊断。可以在面板复制诊断。存在原生对象不再表述为可见播放成功。
- 主窗口新增“打开空场地预览窗口（实验）”，切换为独立原生视图并弹出窗口，默认隐藏预览角色。选择素材仍不新增工程图层。
- 原先 `DrawObject.SetTransparency` 对角色模型不生效，且透明度含义使用错误。改为设置本插件持有的角色副本 Alpha，在提交视图前应用；不修改玩家角色 Alpha。隐藏副本后是否影响附着粒子仍需实测。

FFXIVClientStructs 的 [DrawObject 定义](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/Graphics/Scene/DrawObject.cs) 明确标注透明度虚函数不适用于 CharacterBase。[CharaView](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/UI/Misc/CharaView.cs) 仅证明角色视图接口存在，不能证明其纹理包含完整 VFX 通道。

## 尚未完成

当前没有可操作的游戏窗口。自身中心播放是否恢复可见、光环原路径对照、隐藏角色后粒子是否保留、独立视图的透明粒子及深度，均待当前国服客户端验证。未实现经过验证的专用空场地粒子渲染器；现有 CharaView 适配器属于实验路径，不能将窗口入口或角色隐藏等同于功能完成。

重新加载此版本后，先比较原始路径光环与常规素材，再检查空场地窗口。若无画面，使用“复制播放诊断”，保留对应资源标识和 Dalamud 日志；根据实际资源状态继续定位，不以再次创建对象替代验证。
