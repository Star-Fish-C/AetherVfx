# 验收记录

## 已完成的文件级验证

验证环境：Windows x64、.NET SDK 10.0.400、本机国服 Dalamud API 15 SDK、Penumbra API 1.7.2.4、国服游戏 SqPack。

测试程序覆盖 31 个场景，除原有 AVFX 与 PMP 测试外，还覆盖工程迁移、归档引用、来源去重与联合搜索、失败条目覆盖率、缓存版本失效、暂停取消恢复，以及模拟预览连续切换和启动失败清理。新增覆盖内存加载路径、装备与预览解耦、预览资源映射以及原生指针自然结束后的清理。

本机已实际扫描 1,802,972 个归档条目，发现 56,923 个去重 AVFX，失败 0。该结果证明本机此资源包快照的枚举与读取覆盖，不证明所有特效都能脱离原始场景播放。

对应命令：

```powershell
dotnet run --project tests/AetherVfx.Tests -c Release -- ..\originals
dotnet run --project tools/AetherVfx.Cli -c Release -- demo F:\FF14\Game\game\sqpack artifacts\samples
dotnet run --project tools/AetherVfx.Cli -c Release -- verify artifacts\samples\Equipment.pmp
dotnet run --project tools/AetherVfx.Cli -c Release -- verify artifacts\samples\Weapon.pmp
dotnet run --project tools/AetherVfx.Cli -c Release -- verify artifacts\samples\Accessory.pmp
```

命令输出和文件摘要由交付目录 `artifacts/validation` 记录。测试通过只能证明对应代码及文件结构；不能证明游戏效果正确。
